# Security Policy

## Reporting a vulnerability

Please report security problems in LabDesk or in lab-desk.net privately, through
GitHub's private vulnerability reporting on this repository (Security, Report a
vulnerability). Do not open a public issue for a security problem.

Include the version (Settings, About), the platform, and steps that reproduce
the problem. You will get an acknowledgement, and a fix or a stated decision.

There is no bug bounty programme.

## Scope

- The LabDesk application on Windows, macOS, Linux and Android.
- The lab-desk.net site, its account API and its update service.

Problems in the inherited remote-desktop core that also affect its upstream
project should be reported to that project as well; a fix there reaches LabDesk
at the next core update.
